# docs/ — dónde está cada cosa

| busco… | está en |
|---|---|
| **qué falta** (construir, decidir, probar en sala) | **[PENDIENTES.md](PENDIENTES.md)** — la lista única |
| un plan en curso | [PLAN-NUCLEO-PORTABLE-2026-09-24.md](PLAN-NUCLEO-PORTABLE-2026-09-24.md) · [auditoria-2026-09-02/PLAN.md](auditoria-2026-09-02/PLAN.md) |
| un plan terminado | [planes-cerrados/](planes-cerrados/) |
| una propuesta sin aplicar | [propuestas/](propuestas/) |
| cómo funciona un módulo | los demás `.md` de esta carpeta (uno por módulo, abajo) |

Los documentos de módulo **explican**: cómo funciona, por qué está así y qué lo
puede romper. No son listas de tareas. Si uno dice «falta X», X tiene que estar
también en `PENDIENTES.md`; si no está, o ya se hizo, o se olvidó anotarlo.

Un plan nuevo nace en esta carpeta como `PLAN-<TEMA>-<fecha>.md` y, al
terminarse, se mueve a `planes-cerrados/`.
